## نبذة عن المشروع (Project Overview)

منصة رقمية متكاملة ومخصصة لإدارة وتنظيم الفعاليات والمؤتمرات والأنشطة الأكاديمية والتدريبية والطلابية في **الجامعة الإسلامية بالمدينة المنورة**. تقدم المنصة تجربة استخدام عصرية ومريحة ثنائية اللغة لجميع أطراف العملية التنظيمية:

- **الزوار والعموم (Visitors):** استعراض دليل الفعاليات والبحث المتقدم والتصفية وفق التصنيف والتاريخ ونوع الحضور (حضوري / عن بُعد).
- **الطلاب والحضور (Attendees):** بوابة مخصصة لتسجيل الحضور، إصدار تذاكر إلكترونية مزودة برمز الاستجابة السريعة (QR Code)، إدارة الحجوزات وإلغائها، واستعراض شهادات الحضور المعتمدة.
- **المنظمون والمسؤولون (Organizers):** لوحة تحكم شاملة لإدارة دورة حياة الفعالية بالكامل (إنشاء، تعديل، جدولة، تسعير التذاكر أو إتاحتها مجاناً، إدارة المقاعد، قوائم التحضير ومسح التذاكر، وتصدير التقارير الإحصائية).

## أبرز المميزات (Key Features)

1. **واجهة عربية أصيلة بهوية الجامعة (Arabic-First IU Identity):**
   - تصميم متناسق ومتقن يدعم الاتجاه من اليمين إلى اليسار (RTL) مع خط **Tajawal** ولوحة ألوان الهوية الأكاديمية الرسمية (الأخضر الزمردي `#084b2f`).
   - خلو الواجهات من الإيموجيات العشوائية أو غير الرسمية واعتماد أيقونات SVG رسمية أحادية اللون (`@tabler/icons-react`).
2. **نظام صلاحيات ومصادقة مزدوج (Dual Auth Architecture):**
   - فصل تام ومحكم بين حسابات الحضور وحسابات المنظمين لمنع تصعيد الصلاحيات (Privilege Escalation Prevention).
3. **كتالوج الفعاليات المعتمد للجنة (Curated Demo Catalog):**
   - يحتوي النظام على 8 فعاليات جامعية متنوعة تشمل تخصصات الذكاء الاصطناعي، الأمن السيبراني، الحوسبة السحابية، الابتكار، وريادة الأعمال، بأغلفة متجهية عالية الدقة وأوصاف أكاديمية منظمة.
4. **دعم كامل للغتين (Full Bilingual Localization):**
   - دعم التبديل المباشر بين اللغتين العربية (الأساسية) والإنجليزية مع قلب اتجاه الصفحة (RTL/LTR) وعناصر التحكم بسلاسة عبر مكتبة LinguiJS.
5. **إصدار التذاكر والتحضير الفوري (Ticketing & Check-In):**
   - توليد بطاقات دخول رقمية فريدة برمز QR وإمكانية طباعتها وحفظها وإلغاء التسجيل بسلاسة.
6. **الامتثال لرخصة المصدر المفتوح (Open-Source License Compliance):**
   - احتفاظ كامل بإشعار الإسناد البرمجي المطلوب لمحرك Hi.Events في تذييل الواجهات ورسائل البريد الإلكتروني وفق أحكام رخصة AGPL-3.0 (Section 7b).

## البنية التقنية (Technology Stack)

| المكوّن (Component) | التقنية المستخدمة (Technology) | التفاصيل والإصدار |
|---|---|---|
| **الواجهة الخلفية (Backend)** | PHP ≥ 8.3 / Laravel 11/12/13 | معمارية النطاق الموجه (Domain-Driven Design) |
| **قاعدة البيانات (Database)** | PostgreSQL ≥ 16 | علاقات متكاملة، مؤشرات بحث، ودعم UTF-8 |
| **الواجهة الأمامية (Frontend)** | React 19 + TypeScript + Vite | معالجة وتصيير الواجهات على الخادم (SSR Capable) |
| **تصميم الواجهات (UI/UX)** | Mantine UI + SCSS Modules | متغيرات تصميم مخصصة للجامعة الإسلامية |
| **نظام الترجمة (i18n)** | LinguiJS v4/v5 | قواميس رسائل مجمعة ومحسنة للأداء |
| **المصادقة (Auth)** | JWT (JSON Web Tokens) | جلسات منفصلة ومحكمة للحضور والمنظمين |
| **خادم البريد المحلي (Mail)** | Mailpit | التقاط رسائل التذاكر والتحقق عبر SMTP محلي |

## المتطلبات الأساسية للتشغيل (Prerequisites)

قبل تشغيل المنصة على جهاز حاسب بنظام Windows أو أي نظام تشغيل آخر، تأكد من تثبيت الحزم التالية:

1. **PHP:** الإصدار 8.3 أو 8.4 مع تفعيل الإضافات التالية في ملف `php.ini`:
   - `pdo_pgsql`, `pgsql`, `mbstring`, `openssl`, `curl`, `gd`, `intl`, `fileinfo`, `zip`
2. **Composer:** الإصدار 2.7 أو أحدث لإدارة حزم PHP.
3. **Node.js:** الإصدار 18.x أو 20.x أو أحدث مع مدير الحزم `npm` أو `yarn`.
4. **PostgreSQL:** الإصدار 16 أو أحدث قيد التشغيل على منفذ `55432` (أو المنفذ القياسي `5432` وفق ضبط `.env`).
5. **(اختياري) Mailpit:** لالتقاط واستعراض رسائل البريد الإلكتروني الصادرة محلياً.

## طرق التشغيل (Getting Started)

### الطريقة الأولى: التشغيل التلقائي السريع على Windows (الموصى بها) ⚡

تم تجهيز سكربت فحص وتشغيل متقدم يعمل بنقرة واحدة:

1. انقر نقراً مزدوجاً على الملف: **`Start All.cmd`**  
   (أو افتح موجه الأوامر وشغّل: `Start All.cmd`)
2. يقوم السكربت تلقائياً بما يلي:
   - فحص وجود PHP و Node.js في متغيرات النظام (`PATH`).
   - فحص وتجهيز خادم PostgreSQL والتحقق من الاستجابة السريعة.
   - تهيئة ملفات البيئة للواجهة الخلفية والأمامية وضبط المنافذ محلياً.
   - تشغيل خادم البريد Mailpit تلقائياً في حال وجوده.
   - تشغيل خادم Laravel وخادم React SSR في الخلفية.
   - فتح المتصفح مباشرة على منصة الفعاليات!

**روابط الوصول بعد التشغيل:**
- 🌐 **منصة الفعاليات (Frontend):** `http://127.0.0.1:5680`
- ⚙️ **خادم الواجهة البرمجية (Backend API):** `http://127.0.0.1:8010`
- 📬 **واجهة فحص البريد (Mailpit UI):** `http://127.0.0.1:8225`

### الطريقة الثانية: التشغيل اليدوي خطوة بخطوة (Manual Setup)

إذا كنت تفضل التشغيل اليدوي عبر سطر الأوامر (أو على أنظمة Linux / macOS):

#### 1. تهيئة وتشغيل الواجهة الخلفية (Backend):
```bash
cd backend

# نسخ وضبط ملف البيئة
cp .env.example .env
# تأكد من ضبط بيانات الاتصال بقاعدة البيانات في backend/.env

# تثبيت الحزم وتوليد المفاتيح
composer install
php artisan key:generate
php artisan jwt:secret

# إنشاء الجداول وتوليد الرابط التخزيني
php artisan migrate
php artisan storage:link

# تشغيل خادم التطوير
php artisan serve --host=127.0.0.1 --port=8010
```

#### 2. تهيئة وتشغيل الواجهة الأمامية (Frontend):
```bash
cd frontend

# تثبيت الحزم
npm install

# تجميع ملفات الترجمة
npm run messages:compile

# تشغيل الخادم
npm run dev:ssr
# أو تشغيل نسخة الإنتاج
npm run build && node --import ./instrument.mjs server.js --port 5680
```

## الفحص وضمان الجودة (Testing & Verification)

للتأكد من سلامة النظام وجودة مخرجاته برمجياً:

### 1. فحص كتالوج الفعاليات المعتمد آلياً:
```bash
node scripts/verify-gp2-demo-catalog.mjs
```
يقوم بفحص كافة الفعاليات، استجابة الـ API، ظهور البطاقات والصور المتجهية، وعناوين الأوصاف الأكاديمية باللغتين العربية والإنجليزية.

### 2. فحص بناء الواجهة الأمامية للإنتاج (Frontend Build):
```bash
cd frontend
npm run build
```

### 3. تشغيل اختبارات الواجهة الخلفية (PHPUnit Tests):
```bash
cd backend
php artisan test --testsuite=Unit
```
